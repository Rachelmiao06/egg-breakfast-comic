# 正式背景出图约束（后景换场）

> 已由 `docs/BACKGROUND-SPEC.md` 取代：那份是按现有动画定稿的完整规格和提示词。本文件保留作历史记录。

给出图会话参考。配置在 `src/app/preview/visual/backgrounds.json`；换图只改那里，不改代码。所有坐标都是厨房场景坐标（1536×1024，原厨房画布），蛋的锚点是**脚底中心**。

## 同一颗蛋的路径与落点

| 站点 | 当前锚点 | 由谁控制 | 出图要求 |
|---|---|---|---|
| 锅内 panLaunch | (720, 670)，被锅沿遮挡层挡住脚底 13px | 真实时间循环跳 | 若重画厨房，锅沿遮挡层要与锅身逐像素对齐；锅底留出蛋站立的平面 |
| 桌沿等待区 tableWait | (120, 965)，缩放 0.5（显示约 194 场景像素高） | 真实时间轻跳 | 桌面画到画布最下沿，**左下 0–330 × 760–1024 不放物件**（蛋在这里等，且要避开所有漫画格）；桌面透视为略俯视的水平带，桌沿线大约在 y≈980–1000 |
| 锅铲 spatulaLand | 由接蛋格 p3e 的位置算出：格子 box (380, 470, 900, 512)，铲面在格内 (0.81, 0.53) | 滚动控制飞入、落铲回弹一次 | 不需要背景图；铲面前沿遮挡层可选（与 p3e 同画布对位） |
| 饭碗 | 交接后由画着蛋的漫画格接手 | — | 不需要背景图 |

蛋的飞行弧线由起落点自动算（中点、比两端高 380 场景像素），不写死在图里。

## 背景层与换场

| 背景 | 现状 | 正式图要求 |
|---|---|---|
| 厨房（远景 far / 中景 counter / 主体 mid / 锅沿 pan-rim / 近景 front-right） | 从 kitchen-clean 拆出的现有分层 | 同一 1536×1024 画布、各层逐像素对齐；远景墙面瓷砖要画满整幅（镜头景深位移会露出被挡区域，最多约 ±200 场景像素） |
| 桌面（保留的桌沿） | 复用中景层的木桌 | 一张横向桌面图，1536 宽，至少覆盖 y 860–1024；没有灶台脚、锅柄等伸进桌沿带的东西（现在灶台底部会从纸面下沿露出一点） |
| 浅纸面 | 占位：纯色 #f7eedd，下沿 y=965、羽化 45 | 可以是带极轻纸纹的米白大图（≥1936×1300，覆盖镜头推拉范围）；下沿要能与桌沿自然衔接 |
| 走廊 | 占位（已改为纯色暖米白，见新规格 B2） | 16:10 横图，妈妈走向女儿房的走廊；中心区域会被三格漫画盖住，构图重心放在四周 |

## 镜头范围（新版）

镜头关键帧在 backgrounds.json `camera.keys`：开场全景 (768,560, zoom 1) → 蛋落桌后 (420,860, zoom 1.14) → 接蛋 (600–640, 790–800, zoom 1.08)。正式厨房图在这些焦点与缩放下都不能露出画布边缘。
