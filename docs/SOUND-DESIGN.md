# 声音设计（音乐总监稿）

> 目标：**闭上眼睛只听声音，也知道现在发生什么、谁在场、情绪往哪走。** 之前的声音只有"动作的声音"（滋滋、切菜、倒水），所以单薄；现在补上**配乐 + 角色音色 + 情绪转折**。
> 配乐全部原创合成（`tools/music_build.py`），未经人耳试听——所有电平都是依据推算的初值，请按本页的"怎么调"调。

## 一、三层结构

| 层 | 是什么 | 谁负责 | 在哪 |
|---|---|---|---|
| 1 厨房的真实声音 | 滋滋、房间声、切菜、落锅、淋汁、脚步 | 素材库录音（已有，规则不变） | `audio-map.json` |
| 2 配乐 | 8 条同速循环 stem 随场景进出 | 合成 | `music-map.json` + `useKitchenMusic.ts` |
| 3 音乐事件 | 一次性的小乐句（点子！？接住！"宝宝——"） | 合成 | `music-map.json` 的 stingers |

原则：**第 1 层只在画面里真有动作时响**（2026-11-15 用户的修正，不变）；第 2、3 层负责"静态格也有情绪"——这就是以前缺的东西。

## 二、音色 = 角色（2026-11-15 重做：更暖、更不显眼）

用户听后反馈：**乐器声太明显、像钢琴，想要更暖的厨房音乐**。所以循环配乐里**已经没有钟琴 / 马林巴 / 卡林巴**（它们脆、亮、有"叮"的瞬态，是被听成钢琴的来源），全部改成圆润的指弹吉他 + 轻刷沙锤 + 暖垫音，整体再收掉 3 kHz 以上，混响也变暗。亮的乐器只留在**一次性的小事件**里（点子、接住、划开流黄、蛋喊），而且比之前高频少、更轻。

| 声音 | 代表谁 | 听起来 |
|---|---|---|
| 圆润的指弹吉他扫弦 + 轻刷沙锤 | 家、厨房的律动 | 暖、软 |
| 低一个八度的吉他旋律（妈妈主题） | 妈妈 | 像哼的，不是"弹出来的一个声音" |
| 短促的低音区指弹三音上行 | 蛋 | 蹦，但不亮 |
| 低音拨弦 + 持续垫音 | 厨房的底 | 稳、安心 |
| 挂留和弦 + 蹑手蹑脚的低音区短音 | "不对劲 / 还少点什么" | 悬着，没解决 |
| 小调垫音，稀疏的垫音长音 | 空房间 | 空、远 |
| 指弹分解和弦 | 温柔、近 | 贴着耳朵 |

8 条 stem（96 BPM，各 8 小节 = 20 s，同时起播永远对拍，只靠电平进出）：`home-pad` `home-pluck` `home-bass` `home-melody` `home-sparkle` `tender` `curious` `empty`。

## 三、全片 cue sheet（v2 节拍，23 段）

电平 0–1，再乘总线 0.7；进入阶段从上一段渐变。"★"= 音乐事件。

| # | 段 | 听到什么 | 情绪 |
|---|---|---|---|
| 0 | opening | **只有滋滋 + 房间声**，没有音乐。蛋每落回锅面，马林巴"噗"地响一个音（五声音阶随机）——蛋是有声音的 | 安静、主角是锅 |
| 1 | drop | 轻轻的尤克里里 + 蛋的跳跃动机进来（钟琴 + 马林巴）；镜头跟着蛋，音乐第一次出现 | 一天开始了，轻快 |
| 2 | bag | 低音 + 扫弦（家的律动）出来；妈妈进门 | 暖 |
| 3 | idea | 卡林巴主题第一次出现；★ idea-ding（灯泡亮）落在"先炒个配菜饭吧" | 想到了！ |
| 4 | chop | 只留低音 + 轻扫弦，**给"哒哒哒"让路** | 专注 |
| 5 | stirfry | 律动最足：扫弦 + 低音 + 一点卡林巴 + 一点钟琴；叠在滋啦声下 | 忙、香 |
| 6 | sauce | 卡林巴主题更清楚，律动收一点 | 从容 |
| 7 | missing | 暖的东西全部淡出 → `curious`（挂留和弦）；★ missing-q（两个上行的音，悬着） | "是不是还少点什么……" |
| 8 | prejump | 蹑手蹑脚 + 钟琴暗示蛋的动机 | 要有事发生 |
| 9 | hear | 音乐退到很低；"啵！"自己响 | 嗯？ |
| 10 | listen | 几乎全静，只剩画外的轻跳声 | 屏息 |
| 11 | catch | 律动在**飞行过程中从 0 一路升满**（跟滚动，不跟时间）；★ catch-chord 落在锅铲接住的那一刻，和 catch 落铲声叠在一起 | 飞——接住！ |
| 12 | handoff | 全阵容，最亮；★ handoff-bell | 正好！ |
| 13 | bowl | 换成 `tender`（指弹），律动淡出 | 温柔 |
| 14 | yolk | ★ yolk-cascade（钟琴下行的一串，像蛋黄流下来）+ 垫音鼓起 | 好吃 |
| 15 | call | 很轻的 `tender`；★ mom-call（卡林巴的"宝宝——来吃饭啦"）→ ★ egg-small（钟琴一声"我在这儿……"） | 呼唤、回应 |
| 16 | search | **只剩 `empty`**：小调垫音、稀疏钟声、妈妈主题孤零零的头三个音；脚步声照旧 | 空、找 |
| 17 | eggcall | ★ egg-call（马林巴三个上行音 = "妈！这里！"） | 蛋喊 |
| 18 | return | `tender` 回来，带一点悬 | 回到碗前 |
| 19 | recognize | 卡林巴主题回来；★ egg-small 升高一点 = "嗯！" | 认出来了 |
| 20 | worry | `curious` + `empty` 小调 | 担心 |
| 21 | punchline | 音乐在笑点前一拍淡出；★ punch-dum（一个往下滑的闷声"噗"） | 尴尬的笑点 |
| 22 | closeup | **没有音乐**；三个点各一声**蟋蟀**（cricket，逐个略降调；原来的「嗒」被换掉，2026-11-15 用户：不够明显）；★ end-hold 一个很低、很轻的长音垫在三个点下面，然后安静 | 僵住 |

首页旧节拍（9 段）也有对应：`chop` `stirfry` `sauce` 同上；`notice` / `spatula` 用 `curious`；`catch` 同上；`serve` / `ending` 用 `tender` + 事件。

## 四、混音

- **避让**：前景的动作声（chopHit、落锅、淋汁、放碗…）一响，配乐压低约 3 dB、0.25 s 后回来。
- **不抢对白位置**：有气泡的停留段，律动轻、旋律只在 idea / sauce / handoff / recognize 出现。
- **整体音量**：stem 统一在约 -20 LUFS；总线 0.7；炒菜段音乐总响度约与滋啦声相当。
- **懒加载**：第一次打开声音才下载（约 2.2 MB）。
- 开关：同一个右下角声音按钮；音乐关掉 = 把网址加 `?music=0`，或控制台 `localStorage.setItem("kitchen.musicGain","0")`。

## 五、怎么调（因为没人耳试听过）

1. 整体觉得音乐太响 / 太轻：`?music=0.6` / `?music=1.4` 直接试，满意后改 `useKitchenMusic.ts` 的 `BUS`。
2. 某一段不对：只改 `src/components/kitchen/music-map.json` 那一段的数字，刷新就生效；不要碰 `audio-map.json`。
3. 某条乐器不喜欢：改 `tools/music_build.py` 里对应的 `stem_*` / `stinger_*`，`python3 tools/music_build.py 名字` 只重渲这一条。
4. 验收属性：`<div data-kitchen-music>` 上的 `data-level-*`（每条 stem 当前电平）、`data-fired` / `data-last`（最近的事件）。

## 六、已知限制

- 全部是合成乐器，不是真人演奏：钟琴 / 马林巴 / 卡林巴比较像，吉他一般，**妈妈和蛋的"声音"是乐器模拟，不是人声**。想要更真的，把同名文件换成录音即可，代码不用改。
- `momCall` / `eggCall` / `eggSmall`（audio-map 里预留的人声位）仍然空着；音乐版的 mom-call / egg-call / egg-small 是另一套，将来放了真人声两者会一起响，到时去掉其中一套。
- 没有试听，没有 iOS Safari 实机验证；浏览器里只验证了：解码长度正好 20.000 s（无缝循环）、各段电平随滚动变化、事件按位置触发、控制台无错误。
