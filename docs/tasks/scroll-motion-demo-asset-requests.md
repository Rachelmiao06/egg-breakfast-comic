## 通用要求（每张图都适用）

1. **画布 = 原页面整页 1024×1536**，构图、位置和原页面完全一致，不缩放、不裁切、不移动。我们按原页面坐标直接叠，不再校准。
   - **底图**：原页面的编辑版，只改列出的区域，其余像素尽量不动（可交 PNG/RGB）。
   - **透明图层**：PNG（RGBA），只画列出的物体，放在它在原页面里的原位置，其余全透明。
2. 画风完全沿用原图：同样的深棕描边（页面上约 4–6px）、同样的配色和水彩纸纹理；人物、手、道具不重新设计。
3. 透明边缘干净：不要白边、黑边、发光边；图层里**不要**带框线、对白泡、桌面、背景色、投影（除非另行说明）。
4. **被挡住的部分要画完整**：对白泡后面、别的图层后面的部分照样画出来（会被盖住，但动的时候可能露出来）。
5. **从格子边缘进来的东西要出血**：手臂、袖子画到格子框线外至少 40px（页面范围内能画多少画多少），这样转动时不会在边缘露缝。
6. 位置误差 ±4px 以内。做不到精确对齐时，也必须交整页 1024×1536，不要单独裁成小图。
7. 文件名用下面每节给的名字；原件放桌面 `new pics/`，我们只处理项目副本。
