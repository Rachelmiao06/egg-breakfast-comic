# 漫画页版式规格（主会话维护）

用户 2026-11-13 决定：**暂停给现有人物卡片加动效**。前景改为**有景别变化的完整漫画镜头**，素材由 ChatGPT 重画。新图到位前，先用手绘框线和干净留白把版式和阅读顺序搭好，格内放明确标记的占位。**不要把旧半身人物放大裁切来冒充新镜头**。新漫画图到位后再接动画。

## 通用规则

- **一页 = 一张纸面**：米白纸色，格与格之间是干净的纸面留白（不是透出厨房）。纸面边缘可以是很轻的手撕/毛边或干脆没有边线；**不要**大圆角卡片、投影、顶部进度条、缩略图栏、整屏蒙层。
- **手绘框线**：细棕色（`--ink` #6b4a2b），约 2–2.5px，轻微抖动、四角不完全对齐，像钢笔画的格子。每格框线略有差异，不要所有格子完全一样的容器。可以有一格不画框（局部不规则留白），用来做呼吸。
- **阅读顺序**：从左到右、从上到下（Z 字）。格间距约 16–20px，行与行之间稍大。
- **图片保持原始比例**，用 `object-fit: contain` 或按格子比例出图；绝不拉伸、绝不放大旧素材裁切。
- **文字参与构图**：对白用手绘气泡（尾巴指向说话的人），旁白用贴在格角的小方框，拟声词手写在画面里。中文字体用圆润手写感（可以先用系统圆体占位），字号 ≥ 18px，深棕色。
- **格内清楚、稳定**：有文字的格子不透明、不动、不模糊；厨房只在**纸页外围**和**段落之间**活动，不从格子里透出来。
- **厨房取景**：纸页不要正好盖住锅和跳蛋的中心，让锅和蛋在纸页一侧或下一段之间露出来（可用 `<KitchenScene camera>` 调取景）。
- **占位**：每格内写清"占位 · P? 景别：画面内容 · 比例 · 建议出图尺寸"，用浅色斜线底纹，一眼看出是占位。
