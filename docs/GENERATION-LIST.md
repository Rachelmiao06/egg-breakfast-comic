# 出图清单：分层漫画镜头（按 docs/SCROLL-DESIGN.md 反推，2026-11-14）

## 统一要求（每张都适用）

- **画风基准**（用户最终选定版本）：清楚的深色手绘线条，薄荷绿厨房，暖木色，奶油色衣服，绿色围裙，红锅。妈妈长直发、偏椭圆脸、金色实心水滴耳饰。"宝宝"是女儿，**不要画婴儿**。
- **前景是平面漫画**：纸白底、墨线框、格间留白；不要圆角卡片、不要阴影。纸张纹理很轻，人物和文字清楚。
- **分层规则**（为了格内只动局部）：
  - 同一镜头的所有层用**同一尺寸画布、同一位置**，透明 PNG，叠回去就是完整画面。
  - **底图里被活动层挡住的部分要画完整**（比如手和刀拿走后，砧板、胡萝卜、围裙都要在），不能留洞。
  - 活动层只包含会动的东西，边缘干净无白边；在旁边注明**转轴位置**（例如"手肘约在 (120, 80)"）。
  - 漫画框线画在底图里；**接蛋那一格的框线单独一层**（蛋要越过它）。
  - **对白气泡单独一层**（气泡和里面的字一起画好），方便弹出和避免被挡。
- 命名：`s{段}-{镜头}-{层}.png`，放到 `source/comic-v3/`。
