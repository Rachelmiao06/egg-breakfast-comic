# 出图清单（修订 2，2026-11-14：只保留真正必需的）

原则：**普通前景漫画是完整静态图，不拆层**（对白留在图内即可）。只有**跨景接蛋**这条线需要分层，因为同一颗蛋要从后景飞进前景。比例先不定，等三张构图截图验证后再按版位反推。

## A. 跨景接蛋必需（分层）

| # | 图 | 要求 | 为什么必需 |
|---|---|---|---|
| A1 | **接蛋格·无蛋底图**："来，我接着"，妈妈伸出**空**锅铲 | 画面里**没有蛋**；对白可以画在图内 | 蛋来自后景；底图里再画一颗就会出现两颗蛋 |
| A2 | **接蛋格·框线层** | 与 A1 同画布同位置，透明背景，只有这一格的墨线框 | 蛋越过框线才是"打破次元"，框线要能压在蛋下面 |
| A3 | **锅铲前沿层** | 与 A1 同画布同位置，只有铲面靠近观众的那一条边 | 挡住蛋的下缘，看起来是落在铲上，不是贴在上面 |
| A4 | **饭碗格·饭中央留空** | 端着的饭碗，饭中央空着给蛋落下 | 同 A1，避免两颗蛋 |
| A5 | **饭碗前沿层** | 与 A4 同画布同位置，只有碗的前沿 | 挡住蛋的下缘 |

**按构图验证反推的比例**（2026-11-14 截图验证后）：接蛋格在场景里约占 650×530 场景像素 → A1、A2、A3 用同一张约 **5:4** 画布（建议 1300×1060），铲面落点在画布约 (44%, 57%)；饭碗格约 600×410 → A4、A5 用约 **3:2** 画布（建议 1500×1000），饭中央在约 (49%, 61%)。普通阅读两格叠放（宽格约 2.2:1 + 近景 3:2）已用现有图验证可行，新图按同类比例即可，不强制。

**独立蛋**：先沿用已有的 `source/egg.png`。如果截图里蛋飞进漫画时画风跳得太厉害，再生成一张同一角色的墨线版（透明背景）。
