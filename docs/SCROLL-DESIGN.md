# 滚动与运动设计（feat/visual-direction，2026-11-14）

用户方向：温暖、可爱的**分层动画漫画**。滚动时前景漫画、中景灶台、后景厨房以不同速度运动，配合局部动画和声音，像动画镜头一样连续。漫画内容将按本文末尾的清单**重新生成**；本文先定运动和镜头，图按它来画。

## 1. 两个次元，三个接触点

| | 后景：厨房世界 | 前景：妈妈的漫画 |
|---|---|---|
| 质感 | 有空间感的插画，分层，持续自己动 | 平面手绘漫画：纸白、深色墨线、分格、对白 |
| 运动 | 镜头推拉、前中后景错速、环境循环 | 格子进场 / 停留 / 退场；格内只动该动的局部 |
| 时间 | 真实时间（不滚也在动） | 滚动进度（叙事），格内小动作按真实时间循环 |

两者配色协调但**不混成一种画风**。联系只靠三件事：
1. **视线**：妈妈抬眼看向右边时，镜头已经把锅和跳蛋放在画面右侧，她看的就是后景那颗蛋。
2. **声音**：前景动作声（切菜、下锅、搅汁）和后景滋滋声此消彼长。
3. **打破次元**：只有一次——接蛋时，蛋从后景锅里飞出，**越过漫画的框线**，落在妈妈的锅铲上。在此之前，后景的东西从不进入格子，格子里的东西也从不出框。

## 2. 四套运动及其分工（都已有或将有代码落点）

| 系统 | 由什么驱动 | 负责 | 代码落点 |
|---|---|---|---|
| A 环境循环 | 真实时间 | 蛋在锅里跳、火苗、油泡、蒸汽、厨房轻微视差 | `KitchenCharacters`（已修好：不操作 10 秒蛋一直跳） |
| B 滚动镜头 | 统一时间轴 `timeline` | 镜头推拉平移、前中后景错速、场景衔接、漫画格进退场 | `ScrollDriver` → `beats.json`（唯一节奏来源），新增"镜头关键帧 + 景深系数" |
| C 格内动作 | 真实时间，只在本段"停留"阶段播放 | 切菜只动手和刀、搅汁只动勺和酱面、停手抬眼换头部 | 每个镜头的分层图 + 小循环（Ponpon 做法：固定间隔的循环，或每轮结束自己排下一轮） |
| D 跨景接蛋 | 统一时间轴 | 同一颗蛋从后景锅 → 前景锅铲 → 饭碗 | `Egg`（已有：伸锅铲段落地待命、滚动接管飞行、回滚平滑回锅，全程一颗蛋） |

规则：滚动不替代环境的时间推进；用户停下时厨房仍然活着，前景格子则完全静止、文字清楚。

## 3. 速度设计

### 3.1 层与层之间（同一次滚动，近的动得多）

镜头每移动 1 个单位，各层位移倍数：

| 层 | 倍数 | 说明 |
|---|---|---|
| 漫画格（最近，平面） | 进退场时 1.6–2.0；停留时 0 | 读对白时绝对稳定 |
| 前景物件（桌沿、蛋壳、格纹布） | 1.6 | "桌沿先滑过" |
| 中景（灶台、锅、蛋、火苗） | 1.0 | 镜头推近的主体 |
| 后景（墙、瓷砖、柜子） | 0.35 | "墙只动一点" |

### 3.2 同一元素在故事里的速度变化

每段四个阶段，各配不同曲线，**不统一淡入**：

| 阶段 | 运动 | 曲线 |
|---|---|---|
| 进入 | 从画外滑入，越来越慢 | `power3.out`（减速入场） |
| 动作 | 镜头推近或换景，中速 | `sine.inOut` |
| 停留 | 前景 0 速度；环境照常 | — |
| 退出 | 越来越快地离开 | `power2.in`（加速离场） |

滚动速度只做一点"跟手"余韵：格子进场时最多 0.8° 的倾角，停下 0.6 秒内回正；阅读时完全静止。不用持续摇晃制造层次。

### 3.3 借鉴 The Boat 的两类触发

- **一次性**：元素到屏幕约 90% 处触发一次进场（约 0.2–0.4 秒、`power4.out`、沿指定方向位移 40–60px），回滚不重播。用于小格子、拟声字、对白气泡弹出。
- **连续映射**：属性随时间轴区间线性映射。用于镜头、景深错速、厨房弱化、**声音音量**（The Boat 的音量也是按滚动区间映射的）。

## 4. 逐段编排（完整故事；本轮先做 0–6）

镜头约束：厨房画面里锅和跳蛋在正中，蛋跳得很高。所以**备菜各段镜头推近到约 1.35–1.45 倍，把锅和蛋推到画面右侧约 55–85%**，漫画格排在左侧 3–48%；妈妈看向右边就是看向蛋。

| # | 段 | 停留 | 镜头（B） | 漫画（前景） | 格内动作（C） | 主动作声 |
|---|---|---|---|---|---|---|
| 0 | 开场：活着的厨房 | 流动 120vh | 全景静止；末 30% 开始向灶台推（1.0→1.15），桌沿先滑出画面 | 无。底部小提示 | 环境 A | 滋滋（煎锅） |
| 1 | 想："今天给我家宝宝做点什么呢？" | 📌 备菜 160vh | 进入阶段继续推到 1.4，锅移到右侧；停留时静止 | **接缝转场**：一条毛边墨线从左向右扫过，露出第一格（妈妈开冰箱想）。只在这里用 | 想法气泡里的三个小圆点依次出现（气泡单独一层） | 滋滋降到很轻，冰箱门轻响（可选） |
| 2 | 决定："有了，做个荷包蛋拌饭！" | 📌 备菜 160vh | 静止，轻微漂移 | 第一格加速上移离场；"拿鸡蛋"近景从下方减速升入，"有了"表情特写从右上落入，错开 | 表情格：眼睛一眨、感叹线闪一下（分层） | 拿蛋轻响（单次，可选） |
| 3 | 切菜 | 📌 备菜 180vh | 静止 | 切菜中景从下方像桌沿一样升入；手部近景从左侧滑入，叠在中景右下 | **只动握刀的手和刀**（绕手肘约 1°，三下一组"哒哒哒"，停顿再来）；切下的胡萝卜片轻落 | **切菜哒哒** |
| 4 | 炒配菜 | 📌 备菜 160vh | 极轻推近 1.4→1.45 | 炒菜中景 + 锅内近景 | 只动木铲和锅里的配菜颗粒；进入时"滋啦"一次 | **下锅滋啦**（单次）→ 翻炒 |
| 5 | 调汁 | 📌 备菜 150vh | 静止 | 调汁中景 + 碗内近景 | 只动勺子和酱面旋纹 | **搅汁轻响** |
| 6 | 停手、发现跳蛋 | 📌 备菜尾 180vh | 动作阶段推近 1.45→1.6，对准锅；厨房弱化退到 0 | 前一组格子向下加速离场；反应格：妈妈从低头→抬眼看向右边；肩后视角宽条格（耳朵和空锅）从左滑入 | 头部换姿态（分层，交叉 0.25 秒）；宽条格里的锅是空的，蛋在后景真锅里跳 | 动作声淡出，**滋滋**升起 |
| 7 | 接蛋（下一轮） | 📌 接蛋 | 跟随蛋 | "急什么呀""来，我接着"；锅铲妈妈进入场景层；**框线单独一层，蛋越过框线** | 蛋：跨景飞行（D）；铲面前沿遮挡 | **接蛋轻响** |
| 8 | 放进饭碗、端给你（下一轮） | 📌 饭碗 | 对准饭碗 | "好啦，吃饭。" | 蛋落饭中央；碗前沿遮挡 | **饭碗落桌** |
| 9 | 结尾近景（以后） | 📌 饭碗 | — | 淋汁、划开流黄（静态参考） | 等分层素材 | 淋汁 |

声音规则：任何时刻 = 很轻的环境底声 + **一个**当前动作声 + 必要的单次音效；上一段在本段进入阶段淡出、下一段淡入；单次音效只在向下越过触发点时播一次，停滚、回滚不重复（现有混音器已按此实现）。

## 5. 接缝转场（厨房 → 第一格）

参考 SeamTransitions（MIT，Copyright Codrops）：它用 WebGL 着色器，以分层噪声画出毛边接缝，滚动越快羽化越宽，边缘有一圈加深墨线。我们**不复制它的代码**，用 CSS `mask-image`（预先生成一张噪声灰度图）或 Canvas 2D 噪声多边形，按第 1 段进入阶段的进度推进，前沿加一条 2px 深色墨线。只用这一次。

## 7. 实现顺序（图到位后）

1. 先按第 6 节摆静态构图，截三张关键构图给用户确认。
2. 加镜头关键帧和景深错速（B），检查正常、停滚、快滚、倒滚，没有空滚和镜头跳变。
3. 加格内小循环（C）和头部换姿态。
4. 接缝转场。
5. 声音按第 4 节核对。
6. 录一段连续滚动（无头 Chrome 屏幕录制 → ffmpeg）。

代码沿用：唯一的 `ScrollDriver`、`beats.json`、`KitchenCharacters`、混音器；新组件只放在独立预览路由，不改首页、不合并 main。
