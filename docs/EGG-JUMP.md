# 一次跳跃跨三幕：发现 → 声音停顿 → 伸铲接住

2026-11-14 用户要求，由集成会话定节拍，三个会话共用这一份规格。

- **集成会话**：三幕节拍、声音、集成和验收。
- **接蛋会话**：负责一条连续的蛋轨迹，以及备菜段游走、关键点、辅助线和落铲。
- **后景会话**：负责镜头和构图。

三方用同一套场景坐标（场景像素，脚底中心）和同一个滚动驱动（`<ScrollDriver>` → timeline）。只有接蛋会话的 Egg.tsx 移动蛋，其他会话不另外移动它。

## 总原则
- 全程只有一颗蛋。从锅里跳出来以后，它在整个空间里活动、一直在跳，不再每段都回到右下角待命。
- 高跳只在接蛋前出现一次，是一条连续轨迹：桌面起点 L → 视线相遇点 M → 出画点 E →（画外）→ 重新入画点 R → 铲面接触点 C。
- 蛋出画只是离开取景范围，状态和路线一直在：不淡出销毁，不瞬移回桌面，catch 开始时也不重新生成。
- 不锁滚动。倒滚、停留、快速拖过都不能出现闪现、重复、丢失或漏掉交接。

## 备菜段（opening 之后到 missing）
- 开场锅里的自主小跳保留。
- drop 把蛋落到桌面左侧；之后在 bag → missing 的各段进入阶段里，按滚动沿短弧线换两三次位置，从左到右游走。停留阶段原地按真实时间小跳；阅读时动作收敛，跳得更低、间隔更长。
- 站点要避开漫画格、对白和后景配角。最后一个站点就是起点 L（右侧桌面）。
- prejump 段：蛋在 L 蓄力（现有的 ready）。

### 怎么既按滚动、又能停在 M（2026-11-14 用户补充：位置和速度都要连续）
- 轨迹是一条参数曲线 P(s)，s 从 L（0）经 M、E、R 到 C（1）。
- 目标参数 = max(s_滚动, s_表演)：
  - s_滚动：由时间轴算，hear 退出之前是 0，然后随滚动从 s_M 走到 s_E，listen 里在画外，catch 动作阶段从 s_R 走到 1。
  - s_表演：HEAR_EVENT start 后按真实时间从 0 补间到 s_M（下蹲 + 上升，ease-out，到 M 时速度为 0），之后保持。
- **显示参数不直接等于目标**，而是用临界阻尼弹簧跟随目标（ω 约 18/s）。这样位置和速度都连续：
  - 表演还在上升、滚动又追上来时，不会急停，也不会突然换速；
  - 倒滚时沿曲线平滑退回，不瞬移；
  - 快速滚过时平顺进入对应进度。
- **不二次起跳**：
  - 每次进入只触发一次。
  - 只有蛋确实在 L（显示参数接近 0）时才允许触发；蛋已经在空中时，收到 start 也不重新起跳。
  - reset（倒滚到格子入场之前）只把 s_表演 放回 0，蛋按弹簧落回 L，带落桌回弹。
- **不补放起跳声**：触发时如果蛋已经被滚动带离 L（显示参数大于约 0.02），只接上进度，不放 hopTap / pop。
- E → R 这一段全程在画外（listen 和 catch 进入阶段的取景都看不到），在场景坐标里连续即可。

- **E 出画点**：蛋整颗越过 hear 退出时取景的上缘（脚底 y 小于上缘，再留半个蛋高）。
- **R 重新入画点**：catch 取景上缘之外、铲面右上方，下降线不经过对白泡和妈妈的视线左侧。
