# 音效文件约定

来自素材库的现成录音（Pixabay / Mixkit / Freesound CC0 优先），不在代码里合成。
每加一个文件，在 LICENSES.md 记一行：文件名、来源链接、作者、许可。

| 文件名 | 用途 | 要求 |
|---|---|---|
| sizzle-loop.mp3 | 煎蛋滋滋声，厨房底声 | 8–20 s，首尾可无缝循环，无明显节奏 |
| boil-loop.mp3 | 煮水咕嘟声，更轻一层 | 可循环 |
| plop.mp3 | 蛋落到吐司上的一声"噗" | 单次，< 1 s，柔软不响亮 |
| room-loop.mp3（可选） | 很轻的厨房环境底噪 | 可循环 |

统一 mp3（兼容性最好），或同时给 ogg。响度统一到 -18 LUFS 左右，代码里只做淡入淡出。
